# Figures


Figures are generated from the underlying data and analysis workflows and are not required to run the scripts. 

The main analyses represented include:

- Leaf volatile organic compound (VOC) profiles
- Leaf VOC heatmaps
- Rhizosphere microbiome composition
- Procrustes analysis linking microbiome and metabolite profiles
- Root dry weight
- Biolog EcoPlate functional profiles
- Rhizosphere metabolite profiles

See the main [`README.md`](../README.md) for an overview of the project and the [`scripts/`](../scripts/) directory for the corresponding analysis workflows.
